# کافه مکث

نمونه‌کار فارسی و راست‌چین سایت کافی‌شاپ با طراحی واکنش‌گرا، منوی چهار دسته‌ای، گالری تصاویر، منوی موبایل و اشتراک‌گذاری صفحه.

## اجرا

بدون نصب وابستگی: فایل `index.html` را باز کنید یا از یک سرور استاتیک استفاده کنید:

```sh
python3 -m http.server 8080
```

## شخصی‌سازی

- نام، معرفی و اطلاعات تماس: `index.html`
- آیتم‌ها و قیمت‌های نمونه: `assets/app.js`
- رنگ و چیدمان: `assets/style.css`

اطلاعات کافه و قیمت‌ها نمونه‌اند؛ پیش از استفاده تجاری جایگزین شوند. تصاویر آنلاین از Unsplash و فونت Vazirmatn از Google Fonts بارگذاری می‌شوند؛ نمایش آن‌ها به دسترسی شبکه وابسته است. این نسخه سامانه سفارش یا رزرو آنلاین ندارد.
