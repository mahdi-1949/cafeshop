# کافه مکث

وب‌سایت فارسی و راست‌چین کافی‌شاپ، ساخته‌شده با HTML، CSS و JavaScript بدون وابستگی اجرایی.

## صفحات

خانه، منوی جست‌وجوپذیر، داستان کافه، گالری فیلترپذیر، مجله با سه مقاله، تماس، برنامه‌ریزی قرار، پرسش‌های متداول، حریم خصوصی و صفحهٔ خطای ۴۰۴.

## اجرا و ویرایش

```sh
python3 -m http.server 8080
```

- قالب‌ها و محتوای صفحات: `scripts/build.py`
- تولید مجدد HTML: `python3 scripts/build.py`
- آیتم‌ها و قیمت‌های منو: `assets/menu.json`
- سبک بصری: `assets/style.css`
- تعامل‌ها: `assets/app.js`
- تصاویر و فونت به‌صورت محلی میزبانی می‌شوند.

مگامنو با کلیک و صفحه‌کلید، ناوبری موبایل، جزئیات آیتم‌های منو، بزرگ‌نمایی گالری با کنترل جهت‌نما، انیمیشن‌های مبتنی بر IntersectionObserver و پشتیبانی از reduced motion پیاده شده‌اند. سایت ابزار رهگیری، فرم ارسال یا کوکی اختصاصی ندارد.

## انتشار

GitHub Pages: شاخهٔ `main`، پوشهٔ `/ (root)`؛ فایل `.nojekyll` برای سرو مستقیم فایل‌ها موجود است. آدرس پایه: `https://mahdi-1949.github.io/cafeshop/`.
